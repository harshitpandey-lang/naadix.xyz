# Founder HQ project data provenance

The retired Next.js HQ included a one-time project seed script. Its corrected, non-executable data is preserved in `hq-project-seed-data.json`; the active Supabase database remains authoritative.

The correction pass removed unsupported progress percentages, statuses, technology lists, milestones, dates, contributor names, results, and technical claims. The preserved data retains project names, slugs, categories, factual descriptions, explicitly supplied skills, and the supplied Smart Bike component list.

Do not import this file automatically or clear existing projects before using it. Compare it with the active founder-owned rows and perform any import through a reviewed, owner-scoped migration or authenticated workflow.
